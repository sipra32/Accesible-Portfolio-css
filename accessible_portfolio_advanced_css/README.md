# Accessible Multi-Page Portfolio

## Pages
- `index.html` — Home
- `about.html` — About and skills
- `projects.html` — Projects
- `contact.html` — Accessible contact form

## Accessibility features
- Semantic HTML5 landmarks: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- One meaningful `h1` per page with logical heading hierarchy
- Skip-to-content link
- Keyboard-accessible navigation and controls
- Visible `:focus-visible` indicators
- Descriptive page titles and meta descriptions
- Form labels, required fields, error messages, `aria-invalid`, and live status
- `aria-current` for the active navigation item
- Reduced-motion support
- Responsive mobile navigation
- No information conveyed by color alone
- Decorative icons marked with `aria-hidden`

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Customize
Replace the placeholder email and social links in `contact.html`, and edit the project descriptions to match your actual projects.
